# Retrieval-Augmented Generation (`rag/`)

This Python package contains the heavy lifting for vector search, LLM integrations, and NLP chunking.

## Structure
- `vector_store/`: Adapters for Infinity and Elasticsearch.
- `nlp/`: Chunking algorithms and tokenization.
- `graphrag/`: Graph-based RAG implementations.
- `utils/`: Helper scripts for LLM clients and prompts.
