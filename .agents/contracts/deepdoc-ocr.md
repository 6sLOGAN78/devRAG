# DeepDoc OCR Contract

## OCR Architecture
```text
Image
 ↓
OcrEngine (deepdoc.vision.ocr)
 ↓
PaddleOCR (underlying dependency)
 ↓
normalized OCR detections
 ↓
TextBlock[]
```

## Input Contract
The `OcrEngine.extract()` method expects a `Path` object pointing to a local image file. 
Supported image types include all formats native to OpenCV `cv2.imread()` (e.g., PNG, JPEG, TIFF).
Images are validated prior to invoking the OCR inference model. 
Missing or completely corrupted images will yield an `InvalidInputError`.

## Output Contract
The output is a flat list of `TextBlock` instances mapping exactly to the structural layout specified in Phase 04-01.
- `text`: Preserved UTF-8 transcribed text exactly as detected by the OCR engine.
- `bbox`: `[xmin, ymin, xmax, ymax]` float array.
- `metadata`: Contains a `confidence` float representing the OCR certainty, and a `source` string set to `"paddleocr"`.

## Bounding Box Convention
Coordinates are standardized to a pixel-based origin tracking from the top-left corner `(0, 0)`.
PaddleOCR dynamically yields arbitrary 4-point arrays representing polygons. `OcrEngine` automatically translates these rotated matrices into consistent normalized `[xmin, ymin, xmax, ymax]` cartesian constraints, ensuring strict compatibility across all downstream text processing pipelines.

## Error Behavior
- `InvalidInputError`: Raised explicitly for I/O bounds errors (e.g., missing path, unrecognized file headers) ensuring bad files fail fast.
- `ParsingFailureError`: Wraps any transient or generic runtime issues generated by the underlying Paddle inference graph.
- Empty Lists (`[]`): Legitimate image abstractions containing zero text elements will predictably yield empty arrays without raising artificial failures.

## Configuration
The `OcrEngine` supports `lang="en"` and `use_gpu=False` constructor parameters enabling direct CPU/GPU configuration overrides.
`enable_mkldnn` is deliberately disabled by default due to a known runtime collision bug inside the underlying OneDNN paddlex runtime.
