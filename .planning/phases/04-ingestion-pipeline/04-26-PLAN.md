## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| chunk text, file names and positions from the API to the DOM and to CSS | attacker-influenced content and numbers |
| URL parameters to requests | `id`, `doc`, `page`, `keywords`, `show` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-26-01 | Tampering | markup or script in chunk text | mitigate | text nodes only, hostile-text test asserts no element is created; no Markdown renderer, no iframe |
| T-04-26-02 | Tampering | hostile numbers in positions breaking layout or CSS | mitigate | `boxStyle` rejects non-finite and empty boxes and clamps to 0..100 percent; numbers are never interpolated into style strings unvalidated |
| T-04-26-03 | Information disclosure | token in an image URL | mitigate | images are blobs fetched with the Authorization header; no `src` to an API route |
| T-04-26-04 | Spoofing | requests for the wrong workspace before binding | mitigate | `useDatasetBinding`, FE-02 test |
| T-04-26-05 | Elevation of privilege | switch shown to read-only members | mitigate | `useCanChangeDocument`; 403 shows the lost-permission alert and refetches |
| T-04-26-06 | Denial of service | memory growth from page bitmaps | mitigate | object URLs revoked on change, `gcTime` 60 s, one image per view |
</threat_model>
