## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server strings (file names, progress lines, reasons, thumbnails) to the DOM | all attacker-influenced |
| the SPA's permission helper to the server | the helper only chooses what to draw |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-23-01 | Tampering | markup or script in file names, progress lines, reasons or thumbnails | mitigate | text nodes only, no `dangerouslySetInnerHTML`, thumbnails vetted by prefix in the service, a decode failure falls back to the icon; a hostile name renders as text in a test |
| T-04-23-02 | Elevation of privilege | controls shown to members who may not use them | mitigate | `useCanChangeDocument` draws the controls; the server answers 403 which shows the lost-permission toast and refetches; test per role |
| T-04-23-03 | Repudiation | accidental destructive re-parse | mitigate | server-decided confirmation with counts; 'Keep chunks' default focus; the dialog is not dismissable while the replace is in flight |
| T-04-23-04 | Denial of service | polling load | mitigate | 2000 ms only while something runs, not in hidden tabs, paused notice after three failures |
| T-04-23-05 | Information disclosure | a stale error from one document shown for another | mitigate | dialog body mounted only while open (FE-04), tested |
</threat_model>
