<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client JSON to stored parser configuration | values later drive the worker's chunker |
| worker-written text (progress, log, thumbnail) to API responses to the SPA | stored text is shown to users |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-15-01 | Tampering | malformed or huge `parser_config` stored and hit by a worker | mitigate | `ParserConfig` ranges and types, size cap, `RecursionError` caught; the delimiter is a character set, never a pattern |
| T-04-15-02 | Denial of service | nested JSON causing a 500 | mitigate | typed `parser_config_invalid`; unit test with 1,200 levels |
| T-04-15-03 | Information disclosure | storage location, content hash, internal status or stack text in rows | mitigate | explicit `ROW_KEYS`; failure `message` only from typed codes; leak sweep; progress message redacted and cut to 300 characters |
| T-04-15-04 | Tampering | script or markup in a thumbnail value rendered by the SPA | mitigate | only `data:image/jpeg;base64,` or `data:image/png;base64,` values up to 20000 characters are returned |
| T-04-15-05 | Elevation of privilege | settings write by a non-uploader member or a token | mitigate | `can_remove_document` with `scope.subject`; flow test per role |
| T-04-15-06 | Denial of service | detail polling opening large PDFs repeatedly | mitigate | per `(doc_id, content_hash)` page-count cache; log value preferred; bounded storage executor with timeout |
</threat_model>
