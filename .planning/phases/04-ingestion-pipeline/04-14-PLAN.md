<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client to parse route | document ids, run and confirm flag are caller-controlled |
| route to queue and index | a request triggers cost (embedding) and destructive replacement |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-14-01 | Information disclosure | probing for other tenants' or private datasets' documents | mitigate | dataset visibility first (the one 404); matrix builder proves an outsider gets the same 404 and no state change |
| T-04-14-02 | Elevation of privilege | token or non-uploader member parsing or replacing chunks | mitigate | `can_remove_document` with the permission subject; flow tests for member, uploader and token |
| T-04-14-03 | Denial of service | parse flooding to burn embedding quota | mitigate | per-tenant `FixedWindowLimiter` (`parse_rate_max` per window), at most 100 ids per request, 429 with `Retry-After`; guard test |
| T-04-14-04 | Tampering | accidental destructive re-parse | mitigate | server-decided `confirm_required` with counts, all-or-nothing |
| T-04-14-05 | Information disclosure | queue, SQL or provider text in a response | mitigate | typed `ServiceError`s with fixed messages; the leak sweep scans every body for banned keys and key shapes |
| T-04-14-06 | Spoofing | request body with extra fields to smuggle options | mitigate | `extra="forbid"` request model |
</threat_model>
