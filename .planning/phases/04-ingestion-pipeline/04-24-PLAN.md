## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API responses to SPA state | server text, data URLs and blobs enter component state |
| browser to API for images and downloads | the session token is a header, not a cookie |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-24-01 | Tampering | script or hostile URL via a thumbnail, a blob or a server message | mitigate | explicit field mappers; thumbnails only for two `data:image` prefixes; object URLs only for `image/jpeg` or `image/png`; server text is bounded and rendered as text nodes in later plans; no `dangerouslySetInnerHTML` (source gate in plan 04-35) |
| T-04-24-02 | Information disclosure | token in a URL for images and downloads | mitigate | all binary calls go through `services/http.ts` with the Authorization header; tests assert no `token` or `Authorization` in any built URL |
</threat_model>
