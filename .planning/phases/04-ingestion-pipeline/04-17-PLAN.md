## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client text to embedding provider and index | edit and add send tenant text to a third party and store it |
| client chunk id to engine lookups | ids in paths address documents in a shared tenant index |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-17-01 | Elevation of privilege | non-permitted member or token editing chunks | mitigate | `can_remove_document` with `scope.subject`; per-role e2e |
| T-04-17-02 | Information disclosure | reading chunks of another tenant, a private dataset or another document by id | mitigate | dataset visibility first; every engine call carries the dataset id and `doc_id`; chunk id grammar check; matrix builders |
| T-04-17-03 | Tampering | text without a matching vector in the index | mitigate | embed before write, refusal leaves text and vector untouched (compared byte for byte), no pending state |
| T-04-17-04 | Denial of service | query_string injection or heavy wildcard scans through `keywords` | mitigate | tokenised keywords, escaped `simple_query_string`, keyword length cap, size cap |
| T-04-17-05 | Denial of service | embedding quota burn through add and edit | mitigate | per-tenant fixed-window limit shared with parse; text length and token limits before the provider call |
| T-04-17-06 | Tampering | stored script or markup in chunk text | accept | stored and returned as text; the SPA renders text nodes only (UI rule); no HTML is produced by the API |
| T-04-17-07 | Information disclosure | provider text or keys in an error | mitigate | `bundle_error` scrubbing, refusals carry at most 300 sanitized characters, leak sweep scans bodies |
</threat_model>
