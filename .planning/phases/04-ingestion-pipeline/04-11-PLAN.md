## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored file bytes to parsers and chunker | attacker-controlled content |
| worker to embedding provider | tenant text leaves for a third party; provider text returns |
| worker to index | writes into a shared per-tenant index |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-11-01 | Information disclosure | error text with paths, keys or traces reaching `task.progress_msg`, logs or later the UI | mitigate | failure lines are built from typed codes and fixed sentences, the constructor refuses `/`, `Traceback`; redaction on every stored line; test scans captured logs and rows |
| T-04-11-02 | Tampering | zombie worker writing after re-parse or delete | mitigate | task-row re-check after each insert plus delete by `task_id`; deleted-document test |
| T-04-11-03 | Tampering | chunk id collision or surplus after a shorter retry | mitigate | deterministic ids and `(doc_id, task_id)` delete before the first insert; shrink test |
| T-04-11-04 | Denial of service | one task exhausting memory or connections | mitigate | per-page generators, one page held, DB connection released before inference, bounded limiters and embed pool |
| T-04-11-05 | Tampering | zero or NaN vector poisoning the index | mitigate | L2 normalisation refuses zero and non-finite norms before insert; the doc store also refuses |
| T-04-11-06 | Elevation of privilege | queue message naming a different tenant | mitigate | the pipeline takes only a `TaskContext` loaded from MySQL; tenant id comes from the dataset row |
| T-04-11-07 | Information disclosure | tenant text sent to a provider for another tenant | mitigate | `LLMBundle` is built from `ctx.tenant_id` and `ctx.embd_id` of the dataset row only |
</threat_model>
