## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Valkey stream entry to executor | a message could be forged or corrupted by anything with Valkey access |
| executor to Valkey | outage or eviction can drop queue state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-07-01 | Tampering | forged queue message naming another tenant's task | mitigate | the codec accepts only `task_id` (32 hex) and `digest`; the worker later loads everything from MySQL and drops digest mismatches (plans 04-10 and 04-12) |
| T-04-07-02 | Denial of service | malformed entry blocking the consumer group | mitigate | malformed entries are acknowledged and dropped with a log line carrying no content |
| T-04-07-03 | Elevation of privilege | one worker releasing another worker's lock | mitigate | owner token with compare-and-delete release; test releases from a non-owner |
| T-04-07-04 | Denial of service | task run twice at once after a reclaim | mitigate | every received message passes the lock gate; live owner renews; reclaim idle at least twice the TTL (04-03 validation) |
| T-04-07-05 | Information disclosure | host or password in an error | mitigate | `QueueUnavailable` message is fixed; test asserts it holds neither port nor host |
