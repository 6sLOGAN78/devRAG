<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API responses to SPA state | server text, data URLs and blobs enter component state |
| browser to API for images and downloads | the session token is a header, not a cookie |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-22-01 | Tampering | script or hostile URL via a thumbnail, a blob or a server message | mitigate | explicit field mappers; thumbnails only for two `data:image` prefixes; object URLs only for `image/jpeg` or `image/png`; server text is bounded and rendered as text nodes in later plans; no `dangerouslySetInnerHTML` (source gate in plan 04-31) |
| T-04-22-02 | Information disclosure | token in a URL for images and downloads | mitigate | all binary calls go through `services/http.ts` with the Authorization header; tests assert no `token` or `Authorization` in any built URL |
| T-04-22-03 | Spoofing | request for the wrong workspace before binding (FE-02) | mitigate | `useDatasetBinding` gates every dataset-scoped request; test with a deep link |
| T-04-22-04 | Denial of service | polling storms | mitigate | 2000 ms only while something runs, never in a hidden tab, `retry: false`, paused notice after three failures |
| T-04-22-05 | Repudiation | a timed-out parse that did start looking like it did not | mitigate | invalidation in `onSettled` refreshes the list after any outcome (FE-03) |
</threat_model>
