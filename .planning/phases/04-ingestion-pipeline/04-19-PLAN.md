## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker-written log and task text to API clients | stored text is shown to users |
| client to the embedding check | spends a provider call per request |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-19-01 | Information disclosure | traces, keys, paths or hosts in `error` or `log` | mitigate | `error.message` from fixed sentences by code; `detail` only for `provider_refused`, scrubbed, at most 300 characters; every log line redacted at write time and again at read time; e2e scans the JSON |
| T-04-19-02 | Information disclosure | reading another tenant's or a private dataset's log, task or counts | mitigate | dataset visibility first, found-in-dataset checks, the one 404; matrix builders for log and task ids |
| T-04-19-03 | Denial of service | embedding check used to burn quota | mitigate | manage permission plus the per-tenant limiter |
| T-04-19-04 | Denial of service | very large log lists | mitigate | paging at most 100, log text capped at 3000 lines |
| T-04-19-05 | Spoofing | task id from the `/v1/` family used without dataset checks | mitigate | the task joins to its dataset and passes the same visibility rule as any dataset route |
</threat_model>
