</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-09-01 | Denial of service | zip, DOCX, XLSX, PPTX bomb | mitigate | `check_ooxml_limits` on declared sizes and ratio before extraction; XLSX read-only with a cell cap; test with a ratio bomb |
| T-04-09-02 | Information disclosure | XXE and entity expansion in OOXML XML parts | mitigate | refuse any XML part with DOCTYPE or ENTITY before parsing; test with a `file:///` entity payload |
| T-04-09-03 | Tampering | HTML script or markup surviving into chunk text | mitigate | text extraction only, script and style nodes removed, assertion that no `<` remains; the UI renders text nodes only (UI-SPEC) |
| T-04-09-04 | Information disclosure | parser exception text with paths or cell data | mitigate | exceptions mapped to fixed-message typed errors |
| T-04-09-05 | Denial of service | pathological HTML nesting | accept | lxml handles deep nesting iteratively for the sizes bounded by the upload limit; worker memory is measured in plan 04-35 |
