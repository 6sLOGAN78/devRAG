## Phase Goal

**As an** operator, **I want to** run the parsing worker as its own container and add another by one flag, **so that** parsing scales and a crashed worker is restarted without touching the web server.

<objective>
Package the executor as a compose service with its entrypoint, health probe and dev and test overrides, change Valkey's eviction policy, rebuild the stack once and prove the container runs, registers as a consumer and scales to two.

Purpose: DEPLOY-17, ING-16, D-29 (start at 768m), R-157.
Output: Dockerfile line, two scripts, three compose changes, script and compose tests, a live container test.
</objective>

## Trust Boundaries

| Boundary | Description |

| container to host and network | a new long-running process with credentials for MySQL, Valkey, MinIO, Elasticsearch and the provider key store |
| compose files to production | dev-only settings could leak into the production file |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-13-01 | Elevation of privilege | executor running as root | mitigate | entrypoint drops to `APP_UID:APP_GID` with `setpriv` before `exec`; test inspects the process user |
| T-04-13-02 | Information disclosure | credentials in container logs | mitigate | stdout logging goes through the redactor; test scans logs for the known secrets read via `stack_env()` and never printed |
| T-04-13-03 | Denial of service | queue entries evicted under memory pressure | mitigate | `volatile-lru`, reconciler (plan 04-12); test asserts the policy |
| T-04-13-04 | Tampering | dev SSRF relaxation reaching production | mitigate | `LLM_ALLOW_PRIVATE_BASE_URLS`, `extra_hosts` and `mem_limit` only in the dev override; static test asserts absence from `docker-compose.yml` |
| T-04-13-05 | Denial of service | executor memory exhaustion taking the host down | mitigate | `mem_limit: 768m` in dev, measured in plan 04-31 (D-29); `restart: unless-stopped` |
</threat_model>
