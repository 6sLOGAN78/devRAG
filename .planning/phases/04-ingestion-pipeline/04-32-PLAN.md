## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| file content (HTML, SVG-like, scripts) to the DOM | attacker-controlled |
| download to the user's disk | the file name comes from the server |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-32-01 | Tampering | stored XSS through an HTML or Markdown file | mitigate | `<pre>` text nodes only, no Markdown renderer, no iframe; test with a script payload |
| T-04-32-02 | Tampering | a non-image response shown as an image | mitigate | object URL only for `image/jpeg` or `image/png`; otherwise the error state |
| T-04-32-03 | Information disclosure | token in a URL | mitigate | all fetches use the HTTP client; the download anchor uses a blob URL |
| T-04-32-04 | Tampering | path or script in the downloaded file name | mitigate | the anchor's `download` attribute receives the stored display name; browsers sanitize it; the server also sends a sanitized `Content-Disposition` |
| T-04-32-05 | Denial of service | memory growth on large downloads | accept | a blob download of at most the 100 MiB upload limit is held once; aborted on leaving the page |
</threat_model>
