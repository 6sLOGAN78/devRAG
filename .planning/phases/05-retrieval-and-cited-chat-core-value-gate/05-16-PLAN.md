## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to the completion stream | bearer header on a fetch; server text arrives as frames |
| server text to React state | answer, names, passages are untrusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-16-01 | Information disclosure | token in a URL or sent cross-origin | mitigate | header only, same-origin check before sending, no `EventSource`; tests |
| T-05-16-02 | Denial of service | unbounded buffer or a hung stream | mitigate | buffer cap and 60 s idle watchdog, abort on unmount (hook, plan 05-17) |
| T-05-16-03 | Spoofing | stale token keeps working after logout | mitigate | 401 for the current token calls `purgeSession()`; stale-token 401 does not purge |
| T-05-16-04 | Tampering | malformed frames or references corrupt state | mitigate | `decodeFrame` through `asRecord`/`text`, non-JSON ignored, non-finite numbers become null, final frame replaces text, references addressed by their own `index` |
</threat_model>
