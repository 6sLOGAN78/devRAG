## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client to `/api/v1/datasets/search` | untrusted dataset ids and question text |
| API to OpenRouter-class embedding provider | the question leaves the system; key must not return |
| API to Elasticsearch | per-tenant index plus dataset filter |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04-01 | Information disclosure | retrieval over another workspace's or a private dataset | mitigate | `load_visible_dataset` per id, tenant must equal the acting tenant, one 404 for the whole request; invoker, matrix entry and e2e prove it |
| T-05-04-02 | Elevation of privilege | role without `retrieval_test` | mitigate | `forbid_unless(scope, "datasets", "retrieval_test")` from the generated matrix; API tokens judged by subject |
| T-05-04-03 | Denial of service | spend exhaustion through embedding calls | mitigate | per workspace-and-user rate guard (fail closed), question cap 2000, `size` cap 100, 45 s handler timeout |
| T-05-04-04 | Information disclosure | provider key or question text in logs, responses | mitigate | redacting logger, ids and exception classes only; leak sweep and key scan include the new row |
| T-05-04-05 | Tampering | non-finite floats break JSON consumers | mitigate | `sanitize_floats` at the view edge, test with injected NaN |
| T-05-04-06 | Information disclosure | enumeration of dataset ids by error text | mitigate | identical 404 body for absent, foreign and invisible ids |
</threat_model>
