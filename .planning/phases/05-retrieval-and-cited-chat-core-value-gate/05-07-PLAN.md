<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller to assistant objects | a member must never see or edit another member's private assistant |
| assistant binding to dataset visibility | a shared assistant must not become a path to a private dataset |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-07-01 | Elevation of privilege | owner or admin reading or editing a private assistant | mitigate | `assistant_visible` has no override; `can_manage_assistant` elevates only for `team`; tests for both roles |
| T-05-07-02 | Information disclosure | private dataset text through a shared assistant | mitigate | binding rule on create/update/widen; `resolve_for_chat` re-checks openability per reader at answer time, so a reader who cannot open a dataset never gets its text |
| T-05-07-03 | Tampering | a save silently unbinding a dataset the editor cannot see | mitigate | D-25 keep-hidden algorithm with a test |
| T-05-07-04 | Tampering | race between narrowing and a teammate starting a chat | mitigate | `for_update` on the assistant row; plan 05-09 takes the same lock |
| T-05-07-05 | Information disclosure | enumeration through error text | mitigate | one NOT_FOUND body; offending ids in 409 data limited to ids the caller can open |
| T-05-07-06 | Denial of service | huge icon or prompt | mitigate | 400,000-character icon cap and prefix gate, 8000-character prompt, 20 datasets |
</threat_model>
