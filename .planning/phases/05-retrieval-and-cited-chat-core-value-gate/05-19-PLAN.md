| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-19-01 | Tampering | crafted URL parameters | mitigate | 32-hex validation before any request; anything else ignored |

| T-05-19-04 | Tampering | stored XSS in names, greetings, answers | mitigate | text nodes and `MessageMarkdown` only; markup test |
| T-05-19-05 | Repudiation | deleting teammates' chats without knowing | mitigate | confirmation states the count from the refetched detail (D-26) |
