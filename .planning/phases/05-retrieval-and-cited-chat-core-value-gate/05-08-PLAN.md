## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-08-01 | Information disclosure | IDOR on assistants | mitigate | one NOT_FOUND body for absent, foreign and private; invokers prove owner, admin, member, outsider |
| T-05-08-02 | Elevation of privilege | member editing or deleting a team assistant | mitigate | service FORBIDDEN unless creator, or owner/admin on `team`; e2e cases |
| T-05-08-03 | Denial of service | oversized bodies | mitigate | 1m Nginx limit on the new families, icon cap in the service, pydantic length limits |
| T-05-08-04 | Information disclosure | banned keys or the provider key in responses | mitigate | explicit DTO key list; leak sweep extended |
| T-05-08-05 | Tampering | stored XSS through name or prompt | mitigate | text is stored as given and rendered as text nodes only (plans 05-19, 05-20 and 05-21); no HTML interpretation server-side |
