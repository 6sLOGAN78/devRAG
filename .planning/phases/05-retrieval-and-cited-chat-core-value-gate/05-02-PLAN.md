    - `rrf(rankings, k=60)` takes lists of ids in rank order and returns `{id: sum(1/(k + rank))}` with rank starting at 1; ranks (1,2,3) and (3,1,2) of ids a,b,c give a = 1/61 + 1/63, b = 1/62 + 1/61, c = 1/63 + 1/62 (assert exact fractions).

    - `sanitize_floats(obj)` recursively replaces NaN, +Inf and -Inf with None in dicts, lists and tuples and leaves ints, strings, bools and None unchanged.
