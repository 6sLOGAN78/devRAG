## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-22-01 | Tampering | markup in streamed deltas | mitigate | all text goes through `MessageMarkdown` (no raw HTML, safe links); hostile-delta test |
| T-05-22-02 | Information disclosure | server error sentences shown to the user | mitigate | refusal copy is chosen by status and reason, never the server text |
| T-05-22-03 | Denial of service | hung stream | mitigate | Stop, Esc, unmount abort, and the 60 s idle watchdog from `sse.ts` |
| T-05-22-04 | Repudiation | a lost question after a refusal | mitigate | draft restored and no message added; tested |
| T-05-22-05 | Spoofing | a second turn started while one runs | mitigate | Send is replaced by Stop; the hook ignores a second send; the server answers `turn_in_progress` |
</threat_model>
