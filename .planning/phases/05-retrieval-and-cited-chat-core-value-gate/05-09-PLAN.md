## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| member to another member's session | per-user privacy on a shared assistant |
| stored reference to a later reader | chunk text outlives permission changes |
| app to Valkey | lock and counters |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-09-01 | Information disclosure | reading a teammate's chat | mitigate | every query filters `dialog_id` and `user_id`; one 404 body; invokers and e2e |
| T-05-09-02 | Information disclosure | stale reference exposes a later-private dataset | mitigate | read-time visibility check per distinct dataset id, redacted chunks carry no text |
| T-05-09-03 | Tampering | two concurrent turns corrupt the message list | mitigate | Valkey turn lock plus row-locked read-modify-write; contention is 409 |
| T-05-09-04 | Denial of service | spend or storage exhaustion | mitigate | rate guard (fail closed), session cap 400 messages, question cap, TTL on every Valkey key |
| T-05-09-05 | Tampering | session created after the narrowing check | mitigate | assistant row lock shared with `update_assistant`, test with a held lock |
| T-05-09-06 | Repudiation | feedback on others' or unfinished answers | mitigate | own session only, complete assistant messages only |
</threat_model>
