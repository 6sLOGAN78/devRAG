## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-17-01 | Information disclosure | cached chat data shown after a workspace switch | mitigate | every key starts with `["ws", tenantId]`; queries gated on a known workspace |
| T-05-17-02 | Denial of service | a hung turn or leaked request | mitigate | AbortController held by the turn, aborted on stop and unmount; idle watchdog from `sse.ts` |
| T-05-17-03 | Tampering | stale server state after a failed or stopped turn | mitigate | session and chat list invalidated in `finally` for every ending; the stored message is the truth |
| T-05-17-04 | Repudiation | double spend by a repeated send | mitigate | second send ignored while streaming; retrieval search is a non-retried mutation |
