At the check the host had about 13 GiB free on its filesystem, 15 GiB total RAM with about 6 GiB available, and about 7 GiB of 8 GiB swap occupied. `lspci` showed an Intel graphics controller; no NVIDIA utility was installed.
- The MinerU adapter accepts the `2.x`/`3.x` `/file_parse` response with a JSON-string `content_list`. A separate exact `4.1.6` path accepts the wrapper ZIP with structured content in synthetic tests. Other 4.x versions are refused. Both paths still need real response fixtures.

Standard adds a VLM and has a higher resource burden. A local probe should use Basic with one fixed page and measure actual peak RSS before any broader use.

## Next decision and gate

The recommended investigation is MinerU 4.1.6 Basic on CPU, because the official 3.3.1 Dockerfile targets GPU hardware and its model set is larger. This is a technical recommendation, not an approval or a claim of working inference. The [4.1 HTTP guide](https://github.com/opendatalab/MinerU/blob/mineru-4.1.6-released/docs/en/usage/http_api.md) uses `/v1/tasks`; its [file-parse wrapper](https://github.com/opendatalab/MinerU/blob/mineru-4.1.6-released/docs/en/usage/file_parse.md) accepts `POST /v1/file_parse` and returns a ZIP attachment containing `structured_content.json`, rather than the 3.x JSON `content_list`. The wrapper is a separate service process. A bounded ZIP and normalized `0..1` box adapter now exists with synthetic tests based on [upstream structured-content tests](https://github.com/opendatalab/MinerU/blob/mineru-4.1.6-released/tests/unittest/test_structured_content_render.py). A real fixture and measured CPU run remain outstanding. The operator has been asked which MinerU path to prepare. Once selected, finish an exact package/model/image/license/footprint packet and seek the project checkpoint approval before acquisition. Then run one real Docling and one real MinerU page, retain immutable response fixtures, and verify the saved backend choice through the worker and browser. Plan 06-26 remains incomplete until that evidence exists.
