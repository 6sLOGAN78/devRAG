## Data and protocol invariants

Geometry: one-based page, top-left page units; crop/rotation then exactly one pixel/normalized conversion. Native text and OCR share same type. Missing geometry stays absent. Asset/summary metadata extends dataclasses backward compatibly, not arbitrary unvalidated dicts. All assets record tenant/dataset/document/source linkage and generation; filenames/digests alone confer no permission. Service inputs are bytes with bounded options; never host paths/remote document URLs. Use JSON/binary only, no pickle on a new trust boundary. Model code, weights and dictionary are local/hash-verified before readiness, never downloaded by parse.

Dataset parser_config and declared typed model IDs are trusted only after service validation. Operator endpoints/keys stay in Settings/sealed provider rows, never parser_config or frontend query strings. Use existing URL guard with exact trusted service exceptions, no redirects/private result download without validation. Preserve source text/positions after enrichment. Every DocStore update/delete/insert result follows the existing port's actual return convention and is checked; do not treat insert's nonempty failure list as success.

Task locks/cancellation/current generation are checked at bounded stage boundaries; no open DB connection across inference. Named provider/native/DB executors only. Dataset sentinel jobs have their own context and membership resolution, not Document.get on sentinel. Summary visibility requires every leaf still authorized/enabled; stale descendants cannot expose source data. Public static templates contain no tenant/provider/runtime configuration.
